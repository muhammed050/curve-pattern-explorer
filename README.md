# Curve Pattern Explorer

# Build a Professional secp256k1 Visual Pattern Explorer

Act as a senior cryptography researcher, mathematical visualization engineer, Python developer, and UI/UX designer.

Build a complete, functional, interactive scientific application called:

**secp256k1 Visual Pattern Explorer**

## 1. Project Vision

Create an advanced mathematical laboratory for exploring the geometric distribution of public points generated by the Bitcoin elliptic curve secp256k1.

The application must generate synthetic key pairs, calculate their corresponding public points, visualize those points in an interactive 2D coordinate plane, and allow users to experiment with different mathematical projection algorithms.

The main objective is to study geometric distributions, statistical patterns, neighborhood relationships, and color correlations under different mathematical transformations.

This must be a working scientific application, not a static dashboard or simulated interface.

## 2. Cryptographic Engine

Implement the actual secp256k1 elliptic curve.

Use the official parameters:

- Field prime P
- Group order N
- Generator point G
- Elliptic curve equation: y² = x³ + 7 mod P

Implement:

- Point addition.
- Point doubling.
- Scalar multiplication.
- Public key generation.
- Modular arithmetic.
- Jacobian coordinates for performance.
- Correct conversion from Jacobian to affine coordinates.

Validate the implementation against known secp256k1 test vectors.

Generate synthetic private scalars using a cryptographically secure random number generator.

Never use real wallet private keys or request users to enter them.

## 3. Interactive 2D Visualization

Build a large interactive 2D visualization using Plotly or an equivalent high-performance rendering engine.

Each generated public point must be displayed as a point on the coordinate plane.

Strict mathematical separation:

- X and Y positions must be derived exclusively from public key coordinates.
- Point colors must represent the rank of the synthetic private scalar within the generated sample.
- Private scalar values must never be displayed, exported, or included in chart hover data.
- Projection algorithms must only receive public X and Y coordinates.

Visualization features:

- Zoom.
- Pan.
- Reset zoom.
- Hover over points.
- Display public X and Y values.
- Change point size.
- Change opacity.
- Enable and disable the color scale.
- Show or hide grid lines.
- Export visualization as PNG.
- Export public point coordinates as CSV.

Use WebGL rendering when possible to support large datasets.

## 4. Projection Algorithm Laboratory

Create an interactive algorithm selector.

Include the following algorithms:

1. Original normalized X/Y projection.
2. Linear projection.
3. Rotation transformation.
4. Nonlinear twisting transformation.
5. Polar projection.
6. Radial transformation.
7. Shear transformation.
8. Custom mathematical projection.

Allow users to combine transformations and change their parameters using real-time sliders.

Each parameter change must immediately recalculate the visualization without generating a new sample.

The same sample must remain fixed while experimenting with projection algorithms.

Only the Generate New Sample button should generate new synthetic key pairs.

## 5. Custom Formula Editor

Create a mathematical formula editor where advanced users can define custom projection equations.

Allow formulas such as:

u = X/P - 0.5

v = Y/P - 0.5

x' = f(u,v)

y' = g(u,v)

Requirements:

- Validate expressions before execution.
- Use a safe mathematical expression parser.
- Do not use eval or unrestricted code execution.
- Support common mathematical functions.
- Show formula errors clearly.
- Display the resulting visualization immediately.

## 6. Statistical Analysis Engine

Implement actual statistical measurements.

Display:

- Number of generated points.
- Distribution density.
- Nearest-neighbor distances.
- Average distance between points.
- Minimum and maximum distances.
- Color similarity among neighboring points.
- Global color similarity baseline.
- Spatial distribution statistics.
- Comparison between original and transformed projections.

Create a metric called:

**Local Color Similarity Score**

This metric measures whether spatially neighboring points have more similar sample colors than randomly selected pairs.

Clearly explain that this is a visualization statistic and not a probability of discovering or recovering private keys.

## 7. Comparison Laboratory

Create a side-by-side comparison system.

Show:

- Original projection.
- Selected algorithm projection.
- Before and after statistics.
- Difference in local color similarity.
- Difference in spatial distribution.
- Visual comparison of point density.

Allow users to save experiments with:

- Experiment name.
- Selected algorithm.
- Projection parameters.
- Sample size.
- Statistical results.
- Date and time.

Allow saved experiments to be loaded and compared.

## 8. Advanced Heatmaps

Add optional visualization modes:

- Point density heatmap.
- 2D histogram.
- Kernel density estimation.
- Local neighborhood map.
- Color distribution map.

These modes must use actual generated data.

## 9. Modern Interface Design

Create a professional scientific research dashboard.

Design direction:

- Dark scientific interface.
- Black and deep navy backgrounds.
- Subtle blue and purple accents.
- Clean typography.
- Modern glass-style panels.
- Smooth transitions.
- Responsive layout.
- Excellent desktop experience.
- Usable mobile interface.

Main navigation:

- Overview.
- Point Explorer.
- Algorithm Laboratory.
- Formula Editor.
- Statistical Analysis.
- Experiment Comparison.
- Saved Experiments.
- Settings.

The main visualization must occupy the largest area of the screen.

Keep algorithm controls in a collapsible side panel.

## 10. Performance

The application must support:

- 100 points.
- 500 points.
- 1,000 points.
- 5,000 points.
- 10,000 points, subject to available hardware.

Requirements:

- Avoid unnecessary elliptic curve recalculation.
- Cache generated samples.
- Recalculate projections independently of key generation.
- Use vectorized NumPy operations where appropriate.
- Use efficient nearest-neighbor algorithms.
- Provide progress indicators for expensive operations.
- Keep the interface responsive.

## 11. Technology Stack

Preferred stack:

- Python 3.11+
- Streamlit or a professional React frontend.
- NumPy.
- Plotly.
- SciPy.
- A separate cryptographic calculation module.
- Modular architecture.

Separate the code into:

- cryptography_engine.py
- projection_algorithms.py
- visualization_engine.py
- statistical_analysis.py
- experiment_manager.py
- app.py

## 12. Scientific Integrity and Security

The application must clearly distinguish between mathematical visualization and cryptographic security.

Do not claim that visual clusters, color similarities, or geometric transformations reveal private keys.

Do not implement private-key brute force, wallet scanning, or unauthorized access to Bitcoin wallets.

All generated keys must be synthetic and used only for local mathematical experiments.

## 13. Final Deliverables

Deliver a complete working application with:

- All source code.
- Correct mathematical implementation.
- Functional interactive charts.
- Working algorithm selectors.
- Real-time parameter updates.
- Statistical analysis.
- Experiment saving and comparison.
- Error handling.
- Installation instructions.
- Windows-compatible launch instructions.
- requirements.txt.

Do not deliver mock data, fake buttons, placeholder charts, or nonfunctional controls.

Before considering the project complete, run the application, test every algorithm, verify the chart updates when parameters change, and validate the cryptographic calculations against known test vectors.

**Final objective: Build a real interactive mathematical research laboratory for exploring the geometric and statistical properties of secp256k1 public points.**
